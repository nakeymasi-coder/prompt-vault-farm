One dashboard holds your Prompt Vault Intake Form, your Character Vault for locked characters, your Prompt Log for prompts made or cleaned during runs, solo forms for each of your 5 agents, and a Queue for your runs.

Use a solo form when you want just one agent job by itself. Use the full Prompt Vault Intake Form when you want a complete farm run, all 5 agents in order.

Open the Live Glam Prompt Vault

The Vault holds 1,214 prompts in 33 categories across 4 packs - Classic Prompts (88), Cartoon Prompts (399), Realistic Prompts (613), and Glam Prompt Drop (114) - plus 321 images and 120 color palettes.

How Run in Chat works

  1. Fill in the Prompt Vault Intake Form, or a solo agent form, and add it to the Queue.
  2. Open the Queue and tap Run in Chat on that run. That sets the run to working and opens its Run in Chat card.
  3. Tap Copy Prompt on the Run in Chat card and paste it into chat with Indigo.
  4. Indigo runs that exact run in chat - nothing swapped - starting from the live Vault, and brings the finished piece back to you in chat for your approval.
  5. Back here, set the status yourself when you are ready: queued, working, or done. The status button only changes the label - it never executes anything. Execution happens in chat.

There is no scheduled pickup. Nothing runs on its own and nothing is posted automatically.

Vault First, Create Second

Every run starts by pulling the prompt from the Glam Prompt Vault - by category, pack, prompt name or prompt number, or the Vault Scout searches it. Never invent a prompt when the Vault has one.

New prompts made or cleaned during a run get logged in the Prompt Log to be added back to the Vault, named and categorized the Vault way. Prompts keep the Vault's names and categories, and your favorites in the Vault are never touched by a farm run.

The 5 Agents - in this order

Agent 1 - Vault Scout

Searches the Glam Prompt Vault first (the live link) by category, pack, name, number or keyword and pulls the exact prompt for the run. If the run needs an outfit or product the prompt does not cover, it also searches Pinterest in guest view (no sign-in), especially products with an Amazon link, and copies the picture. Does not check price or availability at this step. If the Vault truly has no fitting prompt, it says so plainly and drafts one in the Vault's style - that draft goes in the Prompt Log as New.

Agent 2 - Image Agent

Creates the person and avatar images in chat from the Vault prompt - character references, the outfit photo (your locked character wearing the exact outfit), and the outfit reference sheet. All ultra realistic, real skin and hair texture, all PNG, all 9:16 for video and character work; a prompt that states its own shape keeps its shape. If a prompt needs cleaning or fixing, the fixed wording goes in the Prompt Log as Cleaned - never silently swapped.

Agent 3 - Story Agent

Writes the hook, the shots, and the script. Labels every scene with the run's one Product Presentation choice. Writes scene ACTION only for video prompts - never a description of the character.

Agent 4 - Video Agent

Makes the video in chat with your AI video tool, using the Consistent Character workflow on this page. Returns the finished video in chat for your approval. Never posts it.

Agent 5 - Caption Agent

Writes the caption, on-screen hook, and hashtags for wherever the finished piece is headed. No price, discount, or sale claim unless a live price was actually verified. Also writes the Prompt Log entry for any prompt the run created or cleaned (Vault name, one of the 33 categories, pack), ready to add back to the Vault.

The 7 Modes

A mode is a setting, not a separate farm. It changes the Vault search, the story structure, the shots, and the captions.

1. Prompt Pull & Polish 2. Portrait Run 3. Typography Run 4. Tee & Product Design Run 5. Get Ready With Me 6. Product Review 7. Full Video Run

Prompt Pull & Polish: the Scout pulls one Vault prompt, cleans or fixes the wording if it needs it, and hands it back ready to copy - logged in the Prompt Log. Portrait Run: a portrait prompt plus your locked character, finished as a PNG portrait. Typography Run: a typography prompt (the Glam Prompt Drop pack is the typography home) finished as lettering art, PNG. Tee & Product Design Run: tee typography or a product prompt finished as a design, shown on a Vault mock-up. Get Ready With Me and Product Review are the classic farm modes, started from a Vault prompt. Full Video Run: Vault prompt to finished video - Scout, Image, Story, Video, Caption, in order.

Product Presentation - one choice per run

Runs with a product pick one single choice, right after Mode: Wearing the product OR Holding the product. Never both. No product? The run stays on No product and no wearing or holding line is added.

Wearing run: every prompt ends with this exact sentence: "Wearing the product, not holding it." Holding run: "Holding the product, not wearing it." Using run: "Using the product on camera, not just holding it." A None run adds no presentation sentence at all.

Never show her wearing an outfit while holding that same outfit on a hanger. Reject and regenerate any image that shows both in the same shot. The mixed choice uses separate scenes - holding first, wearing later - never the same shot.

That one choice is saved on the run and shown on the Queue card and the Run in Chat card, with its exact prompt sentence.

The Workflow - written into every run prompt

  1. Pull the prompt from the Glam Prompt Vault (the live link) - exact prompt, exact wording. Clean or fix only if it needs it, and log the fix in the Prompt Log.
  2. If an outfit is needed beyond the prompt, pick it on Pinterest in guest view (one with an Amazon link when there is a product). Copy its picture.
  3. Lock the outfit IN CHAT, not in the video tool: using your locked character's reference photos, put that character in that exact outfit in chat first. Check face match and outfit match.
  4. Make the outfit reference sheet IN CHAT: from the approved outfit photo, one single 9:16 sheet with front, profile, and three-quarter shots of her in that outfit, all on the same photo. Save as PNG.
  5. Build the video with the Consistent Character lock: Reference One is her headshot (Slot 1). Reference Two is the chat-made outfit reference sheet. NEVER leave Reference Two empty. No character bible is needed - the reference photos ARE the lock. Do not paste descriptions of her into scene prompts.
  6. Create the scenes from that lock, in script order, 9:16.
  7. Export and return the finished piece IN CHAT for your approval. Never post, publish, or share it.

The Scene Prompt Shape - use this, and nothing else about her

"Use the reference images and keep the character perfectly consistent. [Scene action only.] [Spoken line, if any.] Wearing the product, not holding it."

For a Holding run, the last sentence swaps to: "Holding the product, not wearing it."

NEVER describe her in a scene prompt - no face, hair, skin, body, or outfit description. Describing her overrides the references and creates a different girl.

Character lock rules

  • Your characters are ultra realistic, with real skin texture and real hair texture. Every character is African American unless you named a specific existing character. Plus-size stays plus-size, never slimmed down.
  • Slot 1 is one headshot photo, 9:16. Slot 2 is ONE single 9:16 body reference sheet - front, three-quarter, left profile, and right side views of the same person, same outfit, same background, all on that one photo. Not separate photos.
  • A character is NOT locked until BOTH slots are filled.
  • Within one video, identity, clothing, location, and lighting stay frozen from the reference photos.
  • Your uploads are accepted as JPG or PNG, as you saved them. This dashboard never forces your uploads to PNG. If you upload a webp, it is rejected with a clear message: "JPG or PNG please."

Standing rules

  • Every image your AI creates is PNG, never webp. Your own uploaded Vault photos stay as you saved them (JPG or PNG).
  • Nothing is posted automatically, ever. Posting always needs your separate approval.
  • No price, discount, or sale claim in any caption or copy unless a live price was actually verified.
  • Voice and copy everywhere: personable, human, plain words. No em dashes - use hyphens instead.
  • Your characters, Prompt Log, and runs save in this browser on this device. Use Export Backup on the Queue page to keep a copy you can bring back with Import Backup.
